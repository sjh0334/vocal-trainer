# vocal-trainer

## 这个App是什么？

实时音高反馈的练歌工具，核心闭环：用户 -> App实时检测高 -> 和目标应高对比(准/偏高/偏低) -> 唱完出分加诊断指路
核心价值不是功能多，音高检测准+实时反馈直观+评分能指路，这三个是地基，做不扎实再多功能也是空中楼阁。

## 技术栈

js + web Audio API + canvas

练歌App最难的是实时音频采集+音高检测，这是底层API的活，框架帮不上

## 核心算法：

YIN音高检测
音高检测是整个app的命门，不要用简单FFT，用YIN算法，转为单声道基频检测设计，是事实标准。

## 跑道渲染

用canvas绘制，实时更新，是核心功能。

## 评分引擎

分项 权重
稳定度40%
音准30%
气息20%
音量衰减10%
踩过的坑：音准必须用带符号平均偏差的绝对值，不能用绝对值平均，否则颤音会被误判成音准差。 颤音该扣稳定度，不应该扣音准。 音准等于落点准不准。 稳定度等于抖不抖。 两者必须结解耦
